# Lecture 01 - Go Foundations

## Learning Outcomes

- Use essential Go tooling and work with Go modules

- Declare variables and constants using common Go syntax

- Explain Go's basic types and zero values

- Define and call functions with parameters and return values

- Use pointers to access and modify values indirectly

- Explain Go's value semantics and how arguments are passed to functions

## Key Ideas

- Go is a statically typed language with type inference for variable declarations
- `go mod` is used to manage Go modules and dependencies
- `go run` compiles and executes a Go program
- `go build` compiles a Go program into an executable
- `go fmt` formats Go source code according to standard conventions
- Variables can be declared using `var` or short declaration `:=`
- Every variable in Go has a well-defined zero value
- Constants are immutable values known at compile time
- Go does not perform implicit conversions between different numeric types
- Functions can accept multiple parameters and return multiple values
- Go does not support default arguments or function overloading
